## Changed

- **Settings open on the version and the update check.** About was the last card, below the fold in a window of the default size, so Check for updates needed scrolling to. It is the first card now.

## Behind the scenes

- A release is now published only after a reviewer approves it: the packages are built, and nothing is signed or reaches installed copies until then.
- `main` takes changes through pull requests with green checks only, and release tags cannot be moved or deleted.

Copies of 0.23 will offer this version in the sidebar: "Restart to update".
