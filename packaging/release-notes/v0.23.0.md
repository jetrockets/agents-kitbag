The first release from the public repository, and the first that updates itself.

## New

- **Updates.** The app looks for a newer release when it starts and every six hours, and offers it in the sidebar: "Restart to update". Nothing is downloaded until you click. An update is installed only when its checksums carry a valid signature by the key compiled into the app, and the old version is put back if the new one does not start.

  Copies of 0.22 will be offered this release too. From here on, every release reaches installed copies by itself.

## Install

- **macOS:** open `claude-toolkit-v0.23.0-macos-universal.dmg` and drag Claude Toolkit to Applications. Not signed with an Apple Developer ID yet: the first time, right-click, Open, Open.
- **Windows:** unpack `claude-toolkit-v0.23.0-x86_64-pc-windows-msvc.zip` into a folder that will stay and run `claude-toolkit.exe`.
- **Linux:** unpack `claude-toolkit-v0.23.0-x86_64-unknown-linux-gnu.tar.gz` and run `./install.sh`.

## Good to know

- On Windows and Linux an update replaces the app but not `claude-toolkit-runner` beside it. The runner's command line does not change between versions, so the one that came with the first download keeps working.
- A copy run from the disk image, or from a folder a package manager owns, does not update itself. Move the app to Applications.
- Nobody has clicked in the window on a Windows or Linux desktop yet: on those systems the app is built, tested and started in CI only.
